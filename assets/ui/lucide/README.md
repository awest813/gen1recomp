Lucide icons

Source: https://github.com/lucide-icons/lucide/tree/f06ac67e33d645c40b8ce19a0419c85c5d7dd751

ISC license, with Feather's MIT notice: see LICENSE.

White 96-pixel cells rendered from the upstream SVGs and packed left to
right; the UI kit (src/ui/kit/Icons.lua) tints them at draw time.
`icons.png` holds `names` and `editor.png` holds `editorNames`, in the order
Icons.lua lists them.  Regenerate both with `python3 tools/build_ui_icons.py`
(needs cairosvg and Pillow).
